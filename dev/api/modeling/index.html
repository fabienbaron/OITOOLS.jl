OITOOLS.fit_model — Function
fit_model(model_dict, list_free_params, data; kwargs...) -> FitResult

Fit a parametric model to interferometric data using NLopt.

Arguments

  • model_dict::Dict{String} — flat parameter dictionary (values are numbers or expression strings)
  • list_free_params::Vector{String} — names of the free parameters to optimize
  • data::OIdata — interferometric data

Keywords

  • lb, ub — Dict{String,Float64} of lower/upper bounds per parameter (default: ±Inf)
  • weights — observable weights [V2, T3amp, T3phi, visamp, visphi, flux, diffphase]
  • priors — Vector of (expr_str, target, sigma) tuples for Gaussian penalties
  • constraints — relations between parameters that bounds cannot express, as ModelConstraints or (lhs, op, rhs[, tol]) tuples, passed to NLopt as nonlinear constraints; a method that does not support them is wrapped in :AUGLAG. The reported chi2 is the data χ²
  • rv — radial velocities (read_rv) fitted with the interferometry, against the orbit of the model's component on an orbit; their χ² is added, and ndof counts them
  • method — NLopt algorithm (default :LD_LBFGS; use :LN_NELDERMEAD for gradient-free)
  • maxeval — maximum function evaluations (default 2000)
  • ftol_rel, xtol_rel — convergence tolerances
  • nB_workspace — Hankel workspace size (default: nuv from data)
  • verb — print per-evaluation chi2 breakdown
source
fit_model(model::FlatModel, x0, data; kwargs...) -> FitResult

Fit a pre-compiled FlatModel starting from parameter vector x0.

This method skips the dict_to_model step, which is useful when fitting the same model multiple times (e.g. bootstrap, grid search).

Bounds lb and ub can be Dict{String,Float64} (keyed by parameter name) or Vector{Float64} (ordered to match model.list_free_params).

OITOOLS.fit_model_lsqfit — Function
fit_model_lsqfit(model_dict, list_free_params, data; kwargs...) -> LsqFitResult

Fit a parametric model by Levenberg-Marquardt. Returns the covariance and 1σ uncertainties, both scaled to χ²ᵣ = 1.

A parameter that reaches a bound is held there and left out of the step. Besides LsqFit's gradient and step tests, the iteration stops when the Gauss-Newton step would lower χ² by less than 0.001 · max(1, χ²/n) (n data points). reason gives the test that stopped it, and at_bound the parameters held on a bound. The Jacobian is analytic (residuals_flat_jac).

Arguments

  • model_dict::Dict{String} — flat parameter dictionary
  • list_free_params::Vector{String} — names of the free parameters to optimize
  • data::OIdata — interferometric data

Keywords

  • lb, ub — Dict{String,Float64} of lower/upper bounds per parameter
  • weights — observable weights [V2, T3amp, T3phi, visamp, visphi, flux, diffphase]
  • nB_workspace — Hankel workspace size
  • maxIter — maximum iterations (default 200)
  • constraints — relations between parameters that bounds cannot express, as ModelConstraints or (lhs, op, rhs[, tol]) tuples, added as extra rows of the residual vector and the Jacobian, so covar and stderror include them. The reported chi2 excludes them
  • measurement — the measurement model (measurement_model); with visphi = :continuum, each spectral vector's VISPHI residuals are referenced to a polynomial fitted over its continuum channels, as PMOIRED's DPHI (ndof reduced by the coefficients)
  • rv — radial velocities (read_rv) fitted with the interferometry, against the orbit of the model's component on an orbit (c,orb Ka, Kb, gamma, or M and q). They enter the residual vector after the data; chi2 and ndof count them, chi2_rv is their part
  • verb — print per-evaluation chi2 breakdown

OITOOLS.fit_model_nested — Function
fit_model_nested(model_dict, list_free_params, data; kwargs...) -> NestedResult
fit_model_nested(model::FlatModel, data; kwargs...)             -> NestedResult

Fit a parametric model by nested sampling: posterior samples, log-evidence and the maximum-likelihood point. The starting values are not used. Every free parameter needs finite bounds, which define the uniform prior.

using OITOOLS, Nautilus
r = fit_model_nested(model_dict, ["star,ud"], data;
                     lb = Dict("star,ud" => 0.5), ub = Dict("star,ud" => 10.0))
r.logz, r.logzerr        # the evidence, for comparing models
r.posterior              # equally weighted samples, (n_samples, n_params)

backend selects the sampler and defaults to nested_backend(); see set_nested_backend! to change it for a session.

Bounds, constraints and model files

lb/ub bound each parameter. Relations between parameters (a ring's outer diameter larger than its inner one, two fluxes summing to one) are ModelConstraints.

FunctionDescription
default_bounds(model_dict, free; data, max_size)Suggested lb/ub per free parameter; with data, angular sizes are capped at 2 λ/B_min
max_angular_scale(data)The largest angular scale the shortest baseline senses, in mas
ModelConstraint(lhs, op, rhs; tol)A relation between parameters, with op one of <, <=, >, >=, =
parse_constraints(specs)Constraints from ModelConstraints, (lhs, op, rhs[, tol]) tuples (PMOIRED's layout) or dicts
check_constraints(constraints, model_dict)Which constraints the starting model already satisfies
read_model_file(path)Read a TOML model file into (; model, free, lb, ub, constraints, priors, name)
write_model_file(path, model_dict; free, lb, ub, constraints, priors)Write a TOML model file

fit_model passes constraints to NLopt as nonlinear constraints, which hold at the optimum; an algorithm that does not support them (including the default :LD_LBFGS) is wrapped in :AUGLAG. fit_model_lsqfit, fit_model_nested and the samplers add a one-sided quadratic penalty on the normalised violation, as PMOIRED's prior list does; a steep χ² can outweigh it.

A TOML model file holds the model dict, the free parameters, the bounds, the constraints and the priors.

free = ["star,ud", "disk,pa"]

[model]
"star,ud"   = 6.5
"disk,fwhm" = "$star,ud * 3"

[bounds]
"star,ud" = [0.0, 20.0]

[[constraints]]
param = "disk,diamout"
op    = ">"
value = "disk,diamin"
tol   = 0.001

[[priors]]
expr   = "star,ud"
target = 6.0
sigma  = 0.5
m = read_model_file("binary.toml")
res = fit_model(m.model, m.free, data; m.lb, m.ub, m.constraints, m.priors)

free is a top-level key; [model] holds the model dict as it is, global keys included.

OITOOLS.default_bounds — Function
default_bounds(model_dict, list_free_params; data = nothing, max_size = nothing) -> (lb, ub)

Suggested lower and upper bounds for each free parameter, as two Dict{String,Float64} for the fitters' lb/ub.

Bounds are chosen from the parameter's suffix, the part after the first comma ("star,ud" is looked up as "ud"). Azimuthal-mode keys ("c,az amp1", "c,az projang1") are recognised by prefix. Other parameters, including global ones, get (-Inf, Inf).

Angular sizes and offsets are bounded by 2 λ/B_min with data (max_angular_scale), by DEFAULT_MAX_SIZE_MAS without; max_size overrides both.

lb, ub = default_bounds(model_dict, free)              # 100 mas ceiling
lb, ub = default_bounds(model_dict, free; data = data) # sized to this uv coverage

Other bounds: fluxes [0, Inf), thick and croff [0, 1], inclination [0, 90], position angles [-180, 180], u and w [-1, 1], alpha [0, 3], Claret coefficients [-3, 3], azimuthal amplitudes az ampN [0, 1] (PMOIRED leaves them unbounded), and orbit elements (orb …) their own ranges. Nested sampling needs finite bounds, so free fluxes need an upper bound set by hand.

See also display_model, which checks values against bounds.

OITOOLS.ModelConstraint — Type
ModelConstraint(lhs, op, rhs; tol = DEFAULT_CONSTRAINT_TOL)

A relation between model parameters, enforced during fitting.

lhs and rhs are parameter names ("disk,diamout") or expressions over parameter names ("2 * star,ud"); rhs may be a number. op is one of "<", "<=", ">", ">=", "=", as a string or a symbol. tol: see DEFAULT_CONSTRAINT_TOL.

fit_model passes constraints to NLopt as nonlinear constraints. fit_model_lsqfit, fit_model_nested and the samplers apply a one-sided quadratic penalty, which a steep χ² can outweigh; tol is then its stiffness.

ModelConstraint("disk,diamout", ">", "disk,diamin")
ModelConstraint("star,f + disk,f", "=", 1.0)
ModelConstraint("star,ud", "<", 4.0; tol = 0.01)

Global keys (no comma) are written with a \$, as "\$PA", as in a model expression; a bare name with no comma and no arithmetic gets its \$ added.

See also fit_model and read_model_file.

OITOOLS.read_model_file — Function
read_model_file(path) -> (; model, free, lb, ub, constraints, priors, name)

Read a TOML model file into the arguments of the fitters:

m = read_model_file("binary.toml")
res = fit_model(m.model, m.free, data; m.lb, m.ub, m.constraints, m.priors)

Only [model] is required; without free the model has no free parameters. A bound absent from the file is ±Inf (not taken from default_bounds).

An image component's c,image path, when relative, is taken relative to the model file and returned absolute.

OITOOLS.write_model_file — Function
write_model_file(path, model_dict; free, lb, ub, constraints, priors, name)

Write a model and its fit settings to a TOML file readable by read_model_file.

Measurement model

fit_model_lsqfit(…; measurement) sets how the model is compared with spectrally resolved data: differential phases referenced to the continuum of each spectral vector (visphi = :continuum), and PMOIRED's spectral kernel (spectral_kernel). A spectral vector is one table row (a baseline, triangle or telescope at one time) across the wavelengths.

OITOOLS.measurement_model — Function
measurement_model(; visphi = :absolute, order = :auto, continuum = nothing,
                  spectral_kernel = 0, pmoired = false) -> MeasurementModel
  • visphi = :continuum — each spectral vector's phase residuals minus a polynomial in λ of order (:auto: PMOIRED's max(2, ⌊ptp(λ_continuum)/0.2 µm⌋)) fitted over its continuum channels: those outside the model's spectral lines (± 1.5 FWHM for a Gaussian, ± 3 widths for a Lorentzian, PMOIRED's widths), and inside continuum (λ ranges in metres) when given. :absolute (default) compares VISPHI as it is.
  • spectral_kernel = k — PMOIRED's wl kernel: before the comparison (and before visphi = :continuum), the model is smoothed along each spectral vector with a Gaussian of FWHM k channels (2⌊2k⌋ + 3 taps, normalised, edges mirrored): the complex visibility and the complex triple product as phasors, V² separately. PMOIRED's setupFit uses k = 2 for GRAVITY. Only the channels present are smoothed; at the edges of a filtered window the values are mirrored, while PMOIRED smooths across them.
  • pmoired = true — visphi = :continuum computed as PMOIRED's DPHI (computeDiffPhiOI): the continuum is every channel (Gaussian and Lorentzian lines included, truncexp lines excluded), and the data's polynomial is weighted by 1/σ² while the model's is unweighted: (d − Pw d) − (m − Pu m). The default fits one weighted polynomial to the residuals over the channels away from the lines.

Many starts

multistart_fit is PMOIRED's gridFit: Levenberg-Marquardt from every node of a grid (grid = ["p" => (min, max, step)]) and/or from uniform or normal draws (rand, randn, nstarts), without the starts outside constrain. The fits are sorted as in PMOIRED's analyseGrid: failed fits, fits without uncertainties and fits that did not move are set aside, and the rest are grouped into distinct minima, lowest χ²ᵣ first. An explored parameter that is fixed in the model is held at each start's value (PMOIRED's doNotFit), so a grid over held parameters gives a χ² profile. The fits run on threads; start i draws from Xoshiro(seed + i), so the result does not depend on the number of threads. For a component on an orbit, minima whose MJD0 differ by whole periods are merged.

r = multistart_fit(m, ["B,f", "B,x", "B,y"], data; weights = [0, 0, 1, 1, 0, 0, 0],
                   grid = ["B,x" => (-12, 12, 1.5), "B,y" => (-12, 12, 1.5)],
                   constrain = [("sqrt(\$B,x^2 + \$B,y^2)", "<=", 12)])
r.minima[1].fit          # the global minimum, an LsqFitResult
OITOOLS.multistart_fit — Function
multistart_fit(model_dict, list_free_params, data; grid, rand, randn, nstarts, constrain,
               lb, ub, weights, constraints, rv, deltachi2, seed, threaded, maxIter, verbose)
    -> MultiStartResult

Levenberg-Marquardt fits (fit_model_lsqfit) from many starting points, and the distinct minima they reach: PMOIRED's gridFit.

The parameters explored, each in one of

  • grid — "p" => (min, max, step): every node, PMOIRED's count ⌊(max − min)/step + 1⌋ from min to max; several grids make every combination (the first varying slowest);
  • rand — "p" => (min, max): uniform; randn — "p" => (mean, σ): normal; one draw per start;

as a Dict (taken by name) or a vector of pairs (in order). With a grid the number of starts is its node count (draws added to each node); without one, nstarts. The other free parameters start from model_dict. An explored parameter that is not free (a fixed number in model_dict) is held at the start's value in that fit, so a grid over held parameters gives a χ² profile. A start outside lb/ub is moved onto the bound.

constrain drops the starts that violate its conditions, written as constraints (("sqrt($B,x^2 + $B,y^2)", "<=", 12), ModelConstraint). constraints, lb, ub, weights, rv and maxIter apply to every fit, as in fit_model_lsqfit.

The fits are sorted as in PMOIRED's analyseGrid. Fits that failed, have no uncertainties, moved their explored parameters by less than 1σ in all, or end above the best χ²ᵣ + deltachi2 (when given) are set aside. Two of the remaining fits are one minimum when the mean over the free parameters of (bᵢ − bⱼ)²/(σᵢσⱼ), divided again by their number, is below 1 (a gridded held parameter counts, with σ half its step); each minimum is represented by its lowest χ²ᵣ. For a component on an orbit, MJD0 values whole periods apart are the same.

Threads (threaded = true): one compiled model per thread; start i draws its values from Xoshiro(seed + i), so the starts and results do not depend on the thread count.

MultiStartResult

Posterior samplers

Two samplers besides nested sampling return a posterior for the free parameters, with the bounds as a uniform prior and −(χ² + constraint penalty)/2 as the log-likelihood: Ensemble Slice Sampling (the zeus algorithm, gradient-free) and non-reversible parallel tempering with Pigeons.jl, for multimodal posteriors. Both return a SamplerResult; its posterior is drawn by plot_corner_makie and the Modeling tab's corner view.

OITOOLS.fit_model_ensemble — Function
fit_model_ensemble(model_dict, list_free_params, data; lb, ub, weights, constraints,
                   nwalkers = 0, nsweep = 2000, burn = nsweep ÷ 2, thin = 0, seed,
                   verb = true) -> SamplerResult

Sample the posterior of a model's free parameters with Ensemble Slice Sampling (ensemble_slice; Karamanis & Beutler 2020), gradient-free and affine-invariant.

The log-likelihood is −(χ² + constraint penalty)/2; the prior is uniform within the bounds, which may be infinite (an improper prior).

  • nwalkers: 0 for 2d (d free parameters), at least 4, rounded up to an even number.
  • nsweep sweeps kept after burn of burn-in, every thin-th (0: about 2000 kept sweeps at most). The walkers start in a small ball about the model's values, inside the bounds.
  • seed makes the run reproducible.

diagnostics carries R̂ per parameter (rhat; above 1.01, not converged) and τ, the integrated autocorrelation time in sweeps (iat; above about nsweep/50, a lower bound), and the number of evaluations. logz is NaN.

OITOOLS.fit_model_pigeons — Function
fit_model_pigeons(model_dict, list_free_params, data; lb, ub, weights, constraints,
                  n_chains = 10, n_rounds = 10, explorer = :slice, variational = false,
                  n_chains_variational = 0, reference_sigma = 3.0, seed,
                  multithreaded = Threads.nthreads() > 1, verb = true) -> SamplerResult

Sample the posterior with non-reversible parallel tempering (Syed et al. 2021) through Pigeons.jl, for multimodal posteriors. Needs using Pigeons.

The free parameters are mapped to ℝ (a logistic for two finite bounds, lo + exp(z) for one, the identity for none) and the ladder anneals from N(0, reference_sigma²) on those coordinates. The log-likelihood is −(χ² + constraint penalty)/2; the bounds are the prior.

  • n_rounds is a power: the run makes 2^n_rounds scans, each round tuning the ladder for the next. n_chains ≈ 2Λ (the global communication barrier) is the sizing rule.
  • explorer: :slice (no gradient) or :mala (AutoMALA, on the closed-form χ² gradient).
  • variational = true fits a Gaussian reference during the run; n_chains_variational > 0 adds a leg with the fixed reference (the stabilised variant, Surjanovic et al. 2022). On AX Cir's binary (4 parameters, bounds ±60 mas) the fixed reference gives 0–1 round trips at 8–10 rounds, the variational or stabilised reference 76–352.

logz is the stepping-stone evidence on fit_model_nested's scale (the log volume of the bounds subtracted), NaN when a bound is infinite. logzerr is 1/√(round trips) and does not include the bias of a short run: on α Cen A's power-law fit (Nautilus: −712.528), −711.71 at 8 rounds (1 round trip), −712.29 at 10 (18), −712.536 at 12 (103). diagnostics holds the number of round trips; with fewer than 3, other modes may not have been visited.

OITOOLS.ensemble_slice — Function
ensemble_slice(logp, x0; nsweep = 5000, burn = 2000, thin = 10, mu0 = 1.0, tune = true,
               max_expand, maxshrink, patience = 5, tol = 0.05, rng, verb = true)
    -> (chain, logps, diagnostics)

Ensemble Slice Sampling of logp from walkers x0, (nwalkers, ndim), an even number of them. chain is (n_kept_sweeps, nwalkers, ndim) and logps (n_kept_sweeps, nwalkers), the walkers' log-densities.

Each half of the walkers is updated with directions drawn from the other half; the halves are reshuffled every sweep (zeus's shuffle_ensemble=True). mu is tuned during burn-in toward equal numbers of expansions and contractions, and frozen once the balance has held patience times, as in zeus.

Gelman-Rubin R̂ per parameter from a (nsweep, nwalkers, ndim) chain, each walker a chain. Above about 1.01 the chain has not converged. The walkers of an ensemble are coupled, so this R̂ can be low while the ensemble as a whole drifts.

Integrated autocorrelation time in sweeps, averaged over parameters, from a (nsweep, nwalkers, ndim) chain with Sokal's t > 5τ window. OITOOLS.bootstrap_fit — Function
bootstrap_fit(model_dict, list_free_params, data; kwargs...) -> BootstrapResult

Parameter uncertainties by block bootstrap: the model is refitted to nboot replicates in which the blocks of data (by default one per MJD and telescope configuration) are resampled. Correlated calibration errors and wrong error bars appear as scatter between replicates. The blocks must be numerous and exchangeable; with fewer than 10 a warning is printed. See Uncertainties.

Arguments

  • model_dict::Dict{String} — flat parameter dictionary
  • list_free_params::Vector{String} — names of the free parameters
  • data::OIdata — interferometric data

Keywords

  • nboot — number of replicates (default 200; use ≥1000 for stable percentiles)
  • mode — :replacement (default), :halfsample or :weights; see block_counts and block_weights. :pmoired is PMOIRED's scheme, with uncertainties about √2 too small
  • granularity — :config (default), :epoch or :point; see data_blocks
  • fitter — :lsqfit (default, Levenberg-Marquardt with analytic Jacobian) or :nlopt
  • rv — radial velocities (read_rv) fitted with the interferometry (:lsqfit); each replicate resamples them with replacement, as it resamples the blocks
  • lb, ub, weights, nB_workspace — passed through to the fitter
  • method, maxeval — NLopt settings (fitter=:nlopt)
  • maxIter — LsqFit iterations (fitter=:lsqfit)
  • start_scatter — perturb each replicate's starting point by this many σ of the full-data fit (default 0; PMOIRED uses the equivalent of 1). Non-zero values add optimiser scatter to the uncertainty.
  • sigma_clipping — reject replicates beyond this many σ from the median (default nothing; PMOIRED's plots default to 4.5)
  • chi2r_max — reject replicates whose reduced χ² exceeds this value
  • seed — replicate i uses Xoshiro(seed + i), independent of thread scheduling
  • threaded — run replicates on all available Julia threads (default true)
  • verb — progress reporting (default true)

Example

data  = readoifits("data/AlphaCenA.oifits")[1,1]
model = Dict{String,Any}("star,ldlin" => 8.0, "star,u" => 0.3, "star,f" => 1.0)
boot  = bootstrap_fit(model, ["star,ldlin", "star,u"], data;
                      lb=Dict("star,ldlin"=>5.0, "star,u"=>0.0),
                      ub=Dict("star,ldlin"=>12.0, "star,u"=>1.0),
                      weights=[1.0, 0.0, 0.0], nboot=500)

OITOOLS.bootstrap_driver — Function
bootstrap_driver(fitfun, x_opt, list_free_params; kwargs...) -> BootstrapResult

Run nboot bootstrap replicates of any fit and summarise the parameters' scatter: the replicate loop, seeding, threading, failure handling, clipping and statistics of bootstrap_fit, without the model or the resampling.

Arguments

  • fitfun(state, rng) -> (x, chi2r) — one replicate: resample the data, fit, and return the best-fit parameters and the reduced χ². A third element, (x, chi2r, extra), is stored in info.
  • x_opt — best fit to the unresampled data, recorded in the result.
  • list_free_params — parameter names; length sets the expected width of x.

Keywords

  • nboot — number of replicates (default 200)
  • worker_init(w::Int) -> state — per-worker state, built once per worker, serially, before the tasks start. state is nothing without worker_init.
  • nworkers — number of replicate-level workers; 0 (default) means min(nthreads(), nboot). Set it to 1 when fitfun threads internally, so the two levels do not oversubscribe.
  • info — optional AbstractVector of length nboot; info[i] receives replicate i's third element.
  • sigma_clipping, chi2r_max — reject replicates beyond this many σ from the median, or above this reduced χ²
  • seed — replicate i uses Xoshiro(seed + i), so results do not depend on thread scheduling
  • threaded — use several workers (default true; ignored if nworkers is set)
  • verb — progress reporting
  • mode, granularity, nblocks — metadata only, copied into the result

Example

# a fit with no data at all: recover the scatter of a known Gaussian
x_true = [1.0, 2.0]
r = bootstrap_driver((state, rng) -> (x_true .+ 0.1 .* randn(rng, 2), 1.0),
                     x_true, ["a", "b"]; nboot = 500, seed = 1, verb = false)
r.sigma   # ≈ [0.1, 0.1]

OITOOLS.data_blocks — Function
data_blocks(data::OIdata; granularity=:config, mjd_digits=5) -> DataBlocks

Partition data into resampling blocks.

Granularity

  • :config (default) — one block per (MJD, telescope configuration): the baseline for V² and VIS, the triangle for T3, the telescope for FLUX. A block holds all wavelength channels and all observables of that configuration at that MJD (PMOIRED's spectral vector).
  • :epoch — one block per MJD, all baselines and observables.
  • :point — one block per data point (i.i.d. bootstrap). It ignores correlations between channels and observables, so it underestimates uncertainties on real data.

mjd_digits sets the rounding used to group MJDs into a common epoch (default 5 decimals ≈ 0.86 s, matching PMOIRED).

readoifits stores the MJDs (v2_mjd, t3_mjd, vis_mjd, flux_mjd, uv_mjd) as Float64 for any T, so the blocks are the same with T = Float32 and T = Float64.

OITOOLS.resample_blocks — Function
resample_blocks(data, blocks; mode=:replacement, rng=Random.default_rng()) -> OIdata
resample_blocks(data; granularity=:config, mode=:replacement, ...) -> OIdata

Bootstrap replicate of data: the blocks are drawn according to mode (block_counts); a block drawn twice appears twice, a block not drawn is absent. Values and error bars are unchanged. The uv table is unchanged; duplicated points share their uv row.

OITOOLS.block_counts — Function
block_counts(nblocks, mode; rng) -> Vector{Int}

Multiplicity of each block under the resampling mode.

Modes

  • :replacement (default) — nblocks blocks drawn with replacement; multiplicities have mean 1 and variance 1.
  • :halfsample — a random half of the blocks, each once (balanced repeated replication). Each replicate fits half the data. In demos/bootstrap_validation: ratio 0.94–1.06 with 180 blocks, 1.24–1.56 with 18.
  • :pmoired — PMOIRED's scheme: two copies of the dataset, a random half of the blocks dropped in each, the union fitted. Multiplicities are 0/1/2 with probabilities 1/4, 1/2, 1/4 (variance 1/2).
`:pmoired` gives uncertainties √2 too small

In demos/bootstrap_validation it gives 0.62–0.79 of the true scatter, with 1σ coverage near 0.50. It is for comparison with PMOIRED results.

resample_blocks also accepts mode = :weights, the multiplier (Bayesian) bootstrap with continuous weights (block_weights).

OITOOLS.perturb_data — Function
perturb_data(data::OIdata; rng=Random.default_rng()) -> OIdata

A copy of data with independent Gaussian noise added to every observable, scaled by each point's error bar. uv coordinates, flags and the number of points are unchanged.

Refitting such replicates (parametric Monte Carlo) reproduces the analytic covariance of the fit; with correlated calibration errors it gave 11–25× too small an uncertainty in demos/bootstrap_validation. bootstrap_fit estimates uncertainties.
